CASC Cut Times - SigmaNEST sync
===============================
Sends the programs from SigmaNEST to the cut times app (casc-cut-times.netlify.app), so the
operators can pick them on the tablet. Separate from the order book and stock syncs: its own folder,
its own scheduled task ("CASC Cut Times sync") and its own saved key. All can run on the same PC.

SAFE BY DESIGN
- Read-only: SELECT queries only, on a read-only connection, as your Windows login, without locking
  SigmaNEST's tables. It cannot change anything in SigmaNEST.
- The sync key is stored encrypted for your Windows user only (Windows DPAPI).
- Nothing to install: it uses the Windows PowerShell that's already on the PC.
- Only sends when something has changed (plus a small "still here" every 8 minutes).

SET UP (once)
Put this folder somewhere permanent, e.g. Documents\CASC Cut Times sync, then:
1 - Set up and test.bat         Asks for the SQL Server (press Enter: CASC-APPSRV-02\SIGMANEST),
                                the database (Enter: SNDBase), the website (Enter) and the sync key.
                                Then checks it can read SigmaNEST and reach the website. Sends nothing.
2 - Send programs now.bat       Sends everything now. The first time it goes back to 1 Jan 2026,
                                so it takes a few minutes. Then check the tablet.
3 - Turn on automatic sync.bat  Every 2 minutes, 06:00-18:00, Monday to Friday. Runs hidden, wakes
                                the PC from sleep, runs on battery.

OTHER FILES
Check cut times sync.bat        Is it running? Last / next run, any problem, sleep gaps, last log lines.
Stop cut times sync.bat         Switches the automatic sync off.
sync_log.txt                    One line per run: what was read and sent, or the error.

WHAT IT READS (dbo tables, named columns only)
Program, PIP, Wo, Part (Data1 = next op) for programs waiting to be cut;
ProgArchive, PIPArchive, WOArchive, PartArchive for programs completed since 1 Jan 2026.
